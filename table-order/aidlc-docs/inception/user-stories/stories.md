# 테이블오더 서비스 - User Stories

## 분류 방식: Feature-Based
## 세분화 수준: 세부 동작별 (Small)
## Acceptance Criteria: 시나리오 기반 (정상/예외)

---

# Epic 1: 테이블 태블릿 인증 (고객용)

## US-1.1: 테이블 초기 설정 입력
**As a** 관리자  
**I want to** 태블릿에 매장 식별자, 테이블 번호, 비밀번호를 입력할 수 있다  
**So that** 태블릿이 특정 테이블로 인식되어 고객이 바로 주문할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 매장 식별자, 테이블 번호, 비밀번호를 입력하고 저장하면 로그인 정보가 로컬에 저장된다
- 정상 시나리오: 저장 성공 시 메뉴 화면으로 자동 이동한다
- 예외 시나리오: 잘못된 매장 식별자 입력 시 에러 메시지를 표시한다
- 예외 시나리오: 필수 필드 미입력 시 저장 버튼이 비활성화된다

**Personas**: A1, A2, A3

## US-1.2: 자동 로그인
**As a** 고객  
**I want to** 태블릿을 켜면 자동으로 로그인되어 메뉴 화면이 표시된다  
**So that** 별도 인증 절차 없이 즉시 주문할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 저장된 로그인 정보가 있으면 자동으로 인증되어 메뉴 화면이 표시된다
- 정상 시나리오: 브라우저 새로고침 후에도 자동 로그인이 유지된다
- 예외 시나리오: 저장된 정보가 없으면 초기 설정 화면이 표시된다
- 예외 시나리오: 서버 연결 실패 시 재시도 안내 메시지를 표시한다

**Personas**: C1, C2, C3, C4

# Epic 2: 메뉴 조회 및 탐색 (고객용)

## US-2.1: 카테고리별 메뉴 목록 조회
**As a** 고객  
**I want to** 카테고리별로 분류된 메뉴 목록을 볼 수 있다  
**So that** 원하는 종류의 메뉴를 쉽게 찾을 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 로그인 후 메뉴 화면이 기본으로 표시되며 첫 번째 카테고리의 메뉴가 보인다
- 정상 시나리오: 카테고리 탭을 터치하면 해당 카테고리의 메뉴만 표시된다
- 정상 시나리오: 메뉴는 카드 형태로 메뉴명, 가격, 이미지가 표시된다
- 예외 시나리오: 메뉴가 없는 카테고리는 "메뉴 준비 중" 메시지를 표시한다

**Personas**: C1, C2, C3, C4

## US-2.2: 메뉴 상세 정보 확인
**As a** 고객  
**I want to** 메뉴 카드를 터치하여 상세 정보를 볼 수 있다  
**So that** 메뉴 설명과 가격을 확인하고 주문 여부를 결정할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 메뉴 카드 터치 시 메뉴명, 가격, 설명, 이미지가 포함된 상세 화면이 표시된다
- 정상 시나리오: 상세 화면에서 "장바구니 추가" 버튼이 표시된다
- 정상 시나리오: 닫기 버튼으로 메뉴 목록으로 돌아갈 수 있다
- 예외 시나리오: 이미지 URL이 유효하지 않으면 기본 플레이스홀더 이미지가 표시된다

**Personas**: C1, C2, C3, C4

## US-2.3: 카테고리 간 빠른 이동
**As a** 고객  
**I want to** 카테고리 탭을 터치하여 빠르게 다른 카테고리로 이동할 수 있다  
**So that** 여러 카테고리의 메뉴를 효율적으로 탐색할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 화면 상단에 카테고리 탭이 항상 표시된다
- 정상 시나리오: 카테고리 탭 터치 시 즉시 해당 카테고리 메뉴로 전환된다
- 정상 시나리오: 현재 선택된 카테고리가 시각적으로 강조된다
- 예외 시나리오: 카테고리가 많을 경우 좌우 스크롤로 탐색 가능하다

**Personas**: C1, C2, C3, C4

# Epic 3: 장바구니 관리 (고객용)

## US-3.1: 메뉴를 장바구니에 추가
**As a** 고객  
**I want to** 메뉴를 장바구니에 추가할 수 있다  
**So that** 주문할 메뉴를 모아둘 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 메뉴 상세 화면에서 "장바구니 추가" 버튼을 터치하면 수량 1로 장바구니에 추가된다
- 정상 시나리오: 이미 장바구니에 있는 메뉴를 다시 추가하면 수량이 1 증가한다
- 정상 시나리오: 추가 성공 시 시각적 피드백(토스트 메시지)이 표시된다
- 예외 시나리오: 장바구니 데이터 저장 실패 시 에러 메시지를 표시한다

**Personas**: C1, C2, C3

## US-3.2: 장바구니 수량 조절
**As a** 고객  
**I want to** 장바구니에서 메뉴의 수량을 증가/감소시킬 수 있다  
**So that** 원하는 수량으로 정확하게 주문할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: +/- 버튼으로 수량을 조절할 수 있다
- 정상 시나리오: 수량 변경 시 해당 항목의 소계와 총 금액이 즉시 업데이트된다
- 예외 시나리오: 수량이 1일 때 - 버튼을 누르면 해당 항목이 장바구니에서 삭제된다
- 예외 시나리오: 수량이 0 이하로 내려가지 않는다

**Personas**: C1, C2, C3

## US-3.3: 장바구니 항목 삭제
**As a** 고객  
**I want to** 장바구니에서 특정 메뉴를 삭제할 수 있다  
**So that** 주문하지 않을 메뉴를 제거할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 삭제 버튼 터치 시 해당 항목이 장바구니에서 즉시 제거된다
- 정상 시나리오: 삭제 후 총 금액이 즉시 재계산된다
- 예외 시나리오: 마지막 항목 삭제 시 "장바구니가 비어있습니다" 메시지가 표시된다

**Personas**: C1, C2, C3

## US-3.4: 장바구니 비우기
**As a** 고객  
**I want to** 장바구니를 한 번에 비울 수 있다  
**So that** 처음부터 다시 메뉴를 선택할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: "전체 삭제" 버튼 터치 시 확인 팝업이 표시된다
- 정상 시나리오: 확인 시 모든 항목이 삭제되고 총 금액이 0원이 된다
- 예외 시나리오: 취소 시 장바구니가 그대로 유지된다

**Personas**: C1, C2, C3

## US-3.5: 장바구니 총 금액 확인
**As a** 고객  
**I want to** 장바구니의 총 주문 금액을 실시간으로 확인할 수 있다  
**So that** 예산 내에서 주문할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 장바구니 화면에 각 항목의 소계와 전체 총 금액이 표시된다
- 정상 시나리오: 수량 변경/추가/삭제 시 총 금액이 즉시 업데이트된다
- 정상 시나리오: 메뉴 화면 하단에 장바구니 아이콘과 총 금액이 항상 표시된다

**Personas**: C1, C2, C3, C4

## US-3.6: 장바구니 데이터 유지
**As a** 고객  
**I want to** 페이지를 새로고침해도 장바구니 내용이 유지된다  
**So that** 실수로 페이지를 닫아도 선택한 메뉴를 잃지 않는다

**Acceptance Criteria:**
- 정상 시나리오: 브라우저 새로고침 후에도 장바구니 항목과 수량이 그대로 유지된다
- 정상 시나리오: 로컬 스토리지에 장바구니 데이터가 저장된다
- 예외 시나리오: 로컬 스토리지가 가득 찬 경우 사용자에게 알림을 표시한다

**Personas**: C1, C2, C3, C4

# Epic 4: 주문 생성 (고객용)

## US-4.1: 주문 내역 최종 확인
**As a** 고객  
**I want to** 주문 확정 전에 주문 내역을 최종 확인할 수 있다  
**So that** 실수 없이 정확한 주문을 할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 주문하기 버튼 터치 시 주문 확인 화면이 표시된다
- 정상 시나리오: 확인 화면에 메뉴명, 수량, 단가, 소계, 총 금액이 표시된다
- 정상 시나리오: "뒤로가기"로 장바구니 수정이 가능하다
- 예외 시나리오: 장바구니가 비어있으면 주문하기 버튼이 비활성화된다

**Personas**: C1, C2, C3, C4

## US-4.2: 주문 확정
**As a** 고객  
**I want to** 주문 확정 버튼을 터치하여 주문을 전송할 수 있다  
**So that** 매장에서 주문을 접수하고 준비할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 주문 확정 버튼 터치 시 서버에 주문이 전송된다
- 정상 시나리오: 주문 성공 시 주문 번호가 표시된다
- 정상 시나리오: 주문 성공 후 장바구니가 자동으로 비워진다
- 정상 시나리오: 5초 후 메뉴 화면으로 자동 리다이렉트된다
- 예외 시나리오: 주문 실패 시 에러 메시지가 표시되고 장바구니가 유지된다
- 예외 시나리오: 네트워크 오류 시 재시도 안내가 표시된다

**Personas**: C1, C2, C3, C4

# Epic 5: 주문 내역 조회 (고객용)

## US-5.1: 현재 세션 주문 목록 조회
**As a** 고객  
**I want to** 현재 테이블 세션의 주문 내역을 조회할 수 있다  
**So that** 이번 방문에서 주문한 내용을 확인할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 주문 내역 탭 터치 시 현재 세션의 주문 목록이 시간 순으로 표시된다
- 정상 시나리오: 각 주문에 주문 번호, 시각, 메뉴/수량, 금액, 상태가 표시된다
- 정상 시나리오: 이전 세션(이용 완료 처리된)의 주문은 표시되지 않는다
- 예외 시나리오: 주문이 없으면 "아직 주문 내역이 없습니다" 메시지가 표시된다

**Personas**: C1, C2, C3, C4

## US-5.2: 주문 상태 확인
**As a** 고객  
**I want to** 각 주문의 현재 상태(대기중/준비중/완료)를 확인할 수 있다  
**So that** 음식이 언제 나올지 예상할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 각 주문 항목에 상태 배지(대기중/준비중/완료)가 표시된다
- 정상 시나리오: 상태별로 다른 색상으로 구분된다
- 정상 시나리오: 상태 변경 시 화면이 업데이트된다 (새로고침 또는 실시간)

**Personas**: C1, C2, C3, C4

# Epic 6: 매장 관리자 인증 (관리자용)

## US-6.1: 관리자 로그인
**As a** 관리자  
**I want to** 매장 식별자, 사용자명, 비밀번호로 로그인할 수 있다  
**So that** 매장 관리 시스템에 접근할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 올바른 자격 증명 입력 시 관리자 대시보드로 이동한다
- 정상 시나리오: JWT 토큰이 발급되어 브라우저에 저장된다
- 예외 시나리오: 잘못된 자격 증명 입력 시 "아이디 또는 비밀번호가 올바르지 않습니다" 메시지가 표시된다
- 예외 시나리오: 연속 5회 실패 시 일정 시간 로그인이 차단된다
- 예외 시나리오: 필수 필드 미입력 시 로그인 버튼이 비활성화된다

**Personas**: A1, A2, A3

## US-6.2: 세션 유지
**As a** 관리자  
**I want to** 로그인 후 16시간 동안 세션이 유지된다  
**So that** 영업 시간 동안 반복 로그인 없이 시스템을 사용할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 로그인 후 16시간 동안 인증 상태가 유지된다
- 정상 시나리오: 브라우저 새로고침 후에도 세션이 유지된다
- 예외 시나리오: 16시간 경과 후 자동 로그아웃되고 로그인 화면으로 이동한다
- 예외 시나리오: 토큰 만료 시 현재 작업 중인 데이터 손실 없이 로그인 화면으로 이동한다

**Personas**: A1, A2, A3

## US-6.3: 로그아웃
**As a** 관리자  
**I want to** 수동으로 로그아웃할 수 있다  
**So that** 다른 사람이 관리 시스템에 접근하지 못하도록 할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 로그아웃 버튼 클릭 시 세션이 즉시 종료되고 로그인 화면으로 이동한다
- 정상 시나리오: 로그아웃 후 저장된 토큰이 삭제된다
- 예외 시나리오: 로그아웃 후 뒤로가기 버튼으로 관리 화면에 접근할 수 없다

**Personas**: A1, A2, A3

# Epic 7: 실시간 주문 모니터링 (관리자용)

## US-7.1: 테이블별 주문 대시보드 조회
**As a** 관리자  
**I want to** 테이블별 주문 현황을 그리드 형태로 한눈에 볼 수 있다  
**So that** 매장 전체 상황을 빠르게 파악할 수 있다

**Acceptance Criteria:**
- 정상 시나리오: 로그인 후 테이블별 카드가 그리드 형태로 표시된다
- 정상 시나리오: 각 테이블 카드에 테이블 번호, 총 주문액, 최신 주문 미리보기가 표시된다
- 정상 시나리오: 활성 세션이 있는 테이블과 빈 테이블이 시각적으로 구분된다
