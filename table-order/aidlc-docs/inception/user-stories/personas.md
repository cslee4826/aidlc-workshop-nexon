# 테이블오더 서비스 - 사용자 페르소나

---

## 고객 페르소나 (Customer Personas)

### Persona C1: 김민수 (디지털 네이티브)
- **나이**: 28세
- **직업**: IT 회사 직원
- **디지털 숙련도**: 높음
- **주문 패턴**: 혼자 또는 소규모 그룹, 빠른 주문 선호
- **목표**: 최소한의 터치로 빠르게 주문 완료
- **불편사항**: 느린 로딩, 불필요한 단계, 직관적이지 않은 UI
- **시나리오**: 점심시간에 빠르게 메뉴를 선택하고 주문하고 싶음

### Persona C2: 박영희 (디지털 비숙련자)
- **나이**: 62세
- **직업**: 은퇴자
- **디지털 숙련도**: 낮음
- **주문 패턴**: 가족 단위, 천천히 메뉴 탐색
- **목표**: 쉽고 명확한 인터페이스로 실수 없이 주문
- **불편사항**: 작은 글씨, 복잡한 네비게이션, 실수 시 되돌리기 어려움
- **시나리오**: 가족 모임에서 여러 메뉴를 천천히 고르고 주문하고 싶음

### Persona C3: 이준호 (단체 주문자)
- **나이**: 35세
- **직업**: 영업직
- **디지털 숙련도**: 중간
- **주문 패턴**: 대규모 단체 (5-10명), 여러 번 추가 주문
- **목표**: 여러 사람의 주문을 효율적으로 관리
- **불편사항**: 장바구니에서 항목 찾기 어려움, 추가 주문 시 이전 주문 확인 불편
- **시나리오**: 회식에서 여러 차례에 걸쳐 추가 주문을 하고 싶음

### Persona C4: 최수진 (접근성 필요 사용자)
- **나이**: 45세
- **직업**: 교사
- **디지털 숙련도**: 중간
- **접근성 요구**: 시력 저하 (큰 글씨, 높은 대비 필요)
- **목표**: 메뉴 정보를 명확하게 읽고 정확하게 주문
- **불편사항**: 작은 텍스트, 낮은 색상 대비, 터치 영역이 좁음
- **시나리오**: 메뉴 설명과 가격을 명확히 확인하고 주문하고 싶음

## 관리자 페르소나 (Admin Personas)

### Persona A1: 정대표 (매장 사장)
- **나이**: 48세
- **직업**: 식당 사장
- **기술 숙련도**: 낮음~중간
- **업무 상황**: 전체 매장 운영 관리, 피크/비피크 모두 활동
- **목표**: 매장 전체 상황을 한눈에 파악, 매출 관리
- **불편사항**: 복잡한 설정, 기술적 용어, 여러 화면 전환
- **시나리오**: 바쁜 저녁 시간에 전체 테이블 주문 현황을 빠르게 확인하고 싶음

### Persona A2: 김서연 (홀 매니저)
- **나이**: 32세
- **직업**: 홀 매니저/서빙 직원
- **기술 숙련도**: 중간
- **업무 상황**: 피크 시간 집중 근무, 빠른 대응 필요
- **목표**: 신규 주문 즉시 확인, 주문 상태 빠르게 변경
- **불편사항**: 알림 놓침, 주문 상태 변경이 느림, 테이블 찾기 어려움
- **시나리오**: 피크 시간에 밀려드는 주문을 빠르게 처리하고 상태를 업데이트하고 싶음

### Persona A3: 박준영 (아르바이트생)
- **나이**: 22세
- **직업**: 파트타임 직원
- **기술 숙련도**: 높음 (디지털 네이티브)
- **업무 상황**: 교대 근무, 매장 시스템에 익숙하지 않을 수 있음
- **목표**: 빠르게 시스템을 배우고 실수 없이 운영
- **불편사항**: 복잡한 초기 설정, 실수 시 되돌리기 어려움
- **시나리오**: 처음 출근한 날 테이블 설정과 주문 관리를 빠르게 익히고 싶음
