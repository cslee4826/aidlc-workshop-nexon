# Backend - 비기능 요구사항 (NFR)

---

## 1. 성능 요구사항

| 항목 | 목표 | 측정 기준 |
|---|---|---|
| 일반 API 응답 시간 | 200ms 이내 (p95) | 서버 처리 시간 기준 |
| SSE 이벤트 전달 | 1초 이내 | 이벤트 발생~클라이언트 수신 |
| DB 쿼리 | 100ms 이내 (p95) | 단일 쿼리 기준 |
| 동시 SSE 연결 | 최대 50개 | 관리자 동시 접속 |
| 요청 처리량 | 100 req/s | 피크 시간 기준 |

---

## 2. 확장성 요구사항

| 항목 | 사양 | 비고 |
|---|---|---|
| 동시 접속자 | 50~100명 | 고객 + 관리자 합산 |
| 테이블 수 | 30~50개 | 단일 매장 |
| 일일 주문 수 | ~500건 | 피크 시간 집중 |
| SSE 동시 연결 | ~10개 | 관리자 브라우저 탭 |
| DB 연결 풀 | 20개 | 비동기 연결 풀 |

### 확장 전략
- 단일 서버 배포 (현재 규모에 적합)
- 비동기 I/O (FastAPI + asyncio)로 동시성 처리
- DB 연결 풀링으로 리소스 효율화
- 향후 다중 매장 확장 시 수평 확장 고려

## 3. 가용성 요구사항

| 항목 | 목표 | 비고 |
|---|---|---|
| 서비스 가용성 | 99.5% (영업 시간 기준) | 월 ~3.6시간 다운타임 허용 |
| 데이터 보존 | 영구 보존 | 과거 주문 이력 삭제 없음 |
| 백업 주기 | 일 1회 자동 백업 | RDS 자동 백업 |
| 복구 시간 목표 (RTO) | 1시간 이내 | 서비스 복구 |
| 복구 시점 목표 (RPO) | 24시간 이내 | 데이터 손실 허용 범위 |

## 4. 보안 요구사항 (Security Baseline 매핑)

| SECURITY 규칙 | 적용 방안 | 우선순위 |
|---|---|---|
| SECURITY-01 | PostgreSQL TLS 연결, 스토리지 암호화 (RDS 암호화) | 필수 |
| SECURITY-03 | 구조화된 로깅 (JSON), 에러+비즈니스 이벤트, PII 제외 | 필수 |
| SECURITY-04 | 보안 헤더 미들웨어 (CSP, HSTS, X-Content-Type-Options) | 필수 |
| SECURITY-05 | Pydantic 스키마 검증, 파라미터화 쿼리, 요청 크기 제한 | 필수 |
| SECURITY-06 | IAM 최소 권한 정책, 리소스별 접근 제어 | 필수 |
| SECURITY-07 | VPC 내 배포, 보안 그룹 최소 포트, 프라이빗 서브넷 DB | 필수 |
| SECURITY-08 | JWT 검증 미들웨어, 리소스 소유권 확인, CORS 제한 | 필수 |
| SECURITY-09 | 기본 자격증명 제거, 프로덕션 에러 메시지 일반화 | 필수 |
| SECURITY-10 | 의존성 고정(lock file), 취약점 스캔, SBOM 생성 | 필수 |
| SECURITY-11 | 인증 모듈 분리, Rate Limiting, 오용 시나리오 고려 | 필수 |
| SECURITY-12 | bcrypt 해싱, 5회 실패 15분 잠금, Secure/HttpOnly 쿠키 | 필수 |
| SECURITY-13 | 안전한 역직렬화 (Pydantic), CI/CD 접근 제어 | 필수 |
| SECURITY-14 | 인증 실패 알림, 로그 보존 90일+, 모니터링 대시보드 | 필수 |
| SECURITY-15 | 글로벌 에러 핸들러, fail-closed, 리소스 정리 | 필수 |

## 5. 운영 요구사항

### 로깅
| 항목 | 사양 |
|---|---|
| 로깅 수준 | 에러 + 주요 비즈니스 이벤트 |
| 로그 형식 | 구조화된 JSON (timestamp, request_id, level, message) |
| 비즈니스 이벤트 | 주문 생성, 상태 변경, 세션 완료, 로그인 성공/실패 |
| 민감 데이터 | 비밀번호, 토큰 절대 로깅 금지 |
| 보존 기간 | 최소 90일 |

### 모니터링
| 항목 | 사양 |
|---|---|
| 헬스체크 | GET /health 엔드포인트 |
| 메트릭 | 응답 시간, 에러율, 동시 연결 수 |
| 알림 | 5xx 에러 급증, DB 연결 실패, SSE 연결 이상 |

### Rate Limiting
| 엔드포인트 | 제한 |
|---|---|
| POST /api/admin/login | 10 req/min per IP |
| POST /api/tables/login | 10 req/min per IP |
| POST /api/orders | 30 req/min per table |
| 기타 API | 100 req/min per client |
